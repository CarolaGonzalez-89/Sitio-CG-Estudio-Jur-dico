# 🌐 CG - Estudio Jurídico

Sitio web profesional desarrollado para **CG-Estudio Jurídico**, con el objetivo de presentar el estudio, sus servicios y facilitar el contacto con potenciales clientes.

## 📑 Contenido del sitio

El sitio cuenta con 5 secciones principales:

1. **Inicio**  
   - Imagen principal con eslogan y breve descripción del estudio.

2. **Sobre mí**  
   - Formación académica.  
   - Metodología de trabajo y valores.  
   - Imagen personal.

3. **Servicios**  
   - Áreas de práctica:  
     - Derecho de Familia  
     - Derecho Sucesorio  
     - Logo e imágenes ilustrativas.

4. **Asesoría Online**  
   - Explicación de temáticas legales en Derecho de Familia y Sucesorio.  
   - Orientación sobre consultas virtuales.

5. **Contacto**  
   - Medios de comunicación disponibles:  
     - Email  
     - Teléfono  
     - Dirección física

---

## 🛠️ Tecnologías utilizadas

- **HTML5**  
- **CSS3**  
- **Node.js**  
- **Git**  
- **Bootstrap** (para diseño responsivo)  
- **Animate.css** (para animaciones)

---

## 🚀 Funcionalidades principales

- Barra de navegación dinámica para acceder a todas las secciones.  
- **Diseño responsivo**: la barra de navegación se convierte en menú hamburguesa en dispositivos móviles.  
- Animaciones atractivas que mejoran la experiencia del usuario.  
- Estilo moderno y profesional pensado para un estudio jurídico.
